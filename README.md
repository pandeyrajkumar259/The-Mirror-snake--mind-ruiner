# The-Mirror-snake--mind-ruiner
Dual-Sync Snake 🐍. A custom game for Hack Club's Stardance program where you control a Blue and Red snake at the same time. Eat the matching colors, or face brutal speed penalties and length loss.


In this game, You need to keep your focus completely on the game.
Just thinking, preparing and designing the mechanism & challenges tooky whole brain.
Coding wasn't that hard either though I was unaware about few syntaxes & functions. so, I searched about those on social platforms & a bit of Chatgpt (just to ask that particular syntax and to learn)...

This game has 2 array type snakes. (Completely inspired by the typical nokia keypad phone game🥹)...
One snake is blue & the other is red.
The conditions are that blue snake can only eat blue dots & red snake can only eat red dots.
Once the game starts, the snakes cant be paused and moves continuously...

Along with that, The twist is there will be only one control which means when you click Up button then the blue snake will go up but red snake will go down and same for other directions too.

The snakes can't eat other color dot because if they do then they will face consequences of losing there length & the speed will be increased by 10% that too only of the snake which eats tge wrong one, this will lead to control uncertainty & difficulty. + The total point will become half of what it actually was.

If the snakes hit each other or even if any ine hits to a border or another snake then the player will lose the game...


Along with that, if a player eats a wrong dot when the total score is 0 or 1 then too the player loses...
